# 0.2.0

- Этапы входа привязаны к фактическому выбору персонажа, восстановлению пароля, поиску сервера, загрузке сцены, соединению, передаче пароля, проверке входа, получению мира, загрузке области и подготовке персонажа.
- Быстрые завершённые этапы остаются в истории без искусственных задержек; на серверах без пароля его передача не показывается.
- Поздние этапы показываются текстом на штатном экране загрузки, сохраняя оригинальную картинку, подсказки и индикатор игры.

# 0.1.1

- Экран ожидания теперь показывается только до появления штатного экрана загрузки Valheim; оригинальная картинка и подсказки сохраняются.
- Деления этапов заменены плавной непрерывной полосой; заголовок Continue заменён на Loading.

# 0.1.0

- Экран загрузки в оформлении Valheim: поиск сервера, загрузка мира, подключение и подготовка персонажа.
- Хранение зашифрованного пароля для Windows, Linux и macOS.

# 0.0.1

- Кнопка «Продолжить» / Continue в главном меню.
- Автоматический выбор последнего персонажа и подключение к последнему серверу с сохранённым паролем.
- Обновление данных только после успешного входа.
