# Проверки тестовой версии 0.2.0

Экран создаётся при нажатии Continue, до выбора персонажа. Этапы записываются по фактическим вызовам, а не таймеру:

| Этап | Точка интеграции |
| --- | --- |
| Выбор персонажа | Поиск сохранённого профиля и FejdStartup.SelectCharacter |
| Восстановление пароля | Расшифровка сохранённого пароля перед подключением |
| Поиск сервера | FejdStartup.JoinServer и штатный поиск адреса/сетевого механизма |
| Загрузка игровой сцены | FejdStartup.LoadMainScene |
| Подключение к серверу | ZNet.ClientConnect |
| Передача пароля | ZNet.RPC_ClientHandshake при needPassword; штатный запрос не перекрывается |
| Проверка входа | ZNet.SendPeerInfo после отправки сведений при статусе Connecting; на сервере без пароля начинается при ClientHandshake |
| Получение данных мира | ZNet.RPC_PeerInfo на клиенте |
| Загрузка области мира | Успешный статус Connected и Game.FindSpawnPoint, который ждёт готовности области |
| Подготовка персонажа | Game.SpawnPlayer перед созданием/загрузкой персонажа |
| Готово | Game.SpawnPlayer возвращает персонажа; завершение подтверждается успешным сохранением входа |

Мгновенные этапы остаются в истории посещённых состояний. Искусственных задержек и процентов нет; повторные или запоздалые события не возвращают этап назад и не дублируют историю. На сервере без пароля шаг передачи пароля не добавляется.

Перед штатной загрузкой показываются Loading, текущий этап, история и прежняя непрерывная золотистая полоса. Когда Hud.UpdateBlackScreen делает штатный экран видимым, собственный непрозрачный Canvas отключается в том же кадре. Для поздних этапов создаются только две текстовые подписи внутри штатного CanvasGroup: текущий этап и история. Картинка, подсказки, индикатор и прозрачность игры не изменяются. Подписи наследуют штатное затемнение, исчезают после его завершения и освобождаются при отмене или возвращении в меню. Ошибки создания/обновления UI перехватываются и не прерывают подключение.

## Автоматическая проверка

- Release DLL собрана без ошибок. Предупреждение NU1900 связано с недоступностью онлайн-проверки уязвимостей NuGet; сборочный пакет reference assemblies и игровые зависимости не менялись.
- Пройдены 63 проверки на Windows: DPAPI и совместимость старых входов, AES/HMAC и повреждённые данные/ключи, сохранение и атомарная замена записи, полная история быстрых и поздних этапов, повторные и запоздалые события, пропуск передачи пароля для сервера без пароля, защита истории от внешнего изменения, наличие игровых методов/полей, отсутствие System.ValueTuple и Jotunn.
- Проверены новые точки интеграции ZNet.ClientConnect, RPC_ClientHandshake, RPC_PeerInfo, Game.FindSpawnPoint и SpawnPlayer, а также Hud.UpdateBlackScreen, m_loadingScreen и m_loadingTip в установленной сборке Valheim.
- Упаковщик проверяет версии DLL/BepInPlugin/manifest/CHANGELOG и порядок истории, PNG 256x256, оба Unix dllmap, ровно шесть файлов и совпадение содержимого архива с исходниками по SHA-256. README в архиве на английском языке, без номера версии и раздела проверок.
- Сохранения, ключи, игровые библиотеки и исследовательские исходники не включены в пакет или Git.

## Ограничения проверки

Пользователь подтвердил работу кнопки и входа одним нажатием, а также оформление и плавную полосу предыдущего обновления. Новые подписи этапов, их размещение на штатной картинке, история и её исчезновение этой версии ещё требуют проверки в Valheim. Автоматические проверки не воспроизводят Unity UI.

Linux и macOS не запускались. Криптографический код проверен на Windows; chmod и загрузка системных библиотек требуют проверки на этих ОС.

## Установка и история

BuildAndInstall.ps1 собирает DLL и полный Thunderstore ZIP, затем обновляет локальную запись ContinueGame в профиле Default. Установка требует закрытых Valheim и Thunderstore; фоновый Overwolf разрешён. Реестр и прежние файлы сохраняются для отката, установленные файлы проверяются по хешам. Обновление 0.2.0 выполнено в Default при закрытой игре: версия, иконка, кэш и установленные файлы проверены скриптом; прежние файлы сохранены для отката. Публикация пакета не выполнялась.

CHANGELOG.md сохраняет всю реальную историю разработки, включая нулевые версии. CHANGELOG.release.md содержит отдельный черновик первого публичного релиза без нулевых версий; он будет выбран для финального архива только по команде на публикацию. Публичный GitHub-репозиторий содержит исходники, иконку, манифест, документацию и оба журнала; архив, тег и GitHub-релиз не публиковались. README на английском языке.

## Проверка в игре

1. Запустить профиль Default с модами и нажать Continue.
2. Проверить, что при поиске сервера в истории уже видны выбор персонажа и восстановление пароля; Loading и непрерывная полоса сохраняют прежнее оформление.
3. После перехода на стандартную картинку проверить текущие этапы соединения, проверки входа, получения мира, загрузки области и подготовки персонажа. Штатная картинка, подсказки и индикатор должны сохраняться; подписи не должны мешать им.
4. После появления персонажа убедиться, что подписи исчезли вместе со штатной загрузкой. Повторить после перезапуска, с недоступным сервером, с ошибочным паролем и на сервере без пароля.

На Linux/macOS установить оба файла мода рядом в работающий BepInEx. Проверить вход после перезапуска, права каталога ключа 0700 и файла 0600, предупреждение при отсутствии ключа. Не распространять файл входа и ключ.
